# Approved GiyaHero reference

Source: user-provided `C:\Users\Ranj\Downloads\GiyaHero.png`, a 15008 × 4993 export of the approved Figma board.

Figma file: https://www.figma.com/design/7U2DV6zXj5NuMKexDMmIQn/GiyaHero

Selected screen crops are kept here for comparison. Supplied brand and destination images were extracted to `public/images` rather than replaced with invented assets.

The `/` frontend includes welcome, home, trip planning, matching packages, agency profiles and gallery, quotations, comparison, saved trips, a reference map, and recommendations. It uses local sample data. Requests do not contact an agency or create bookings; saved trips last for the current session. Agency verification badges and reviews are illustrative. Gabby performs local package filtering, not an AI or live availability lookup. The map is a static source image.

Authentication and agency verification routes remain separate from this preview.
