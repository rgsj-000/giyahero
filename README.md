# GiyaHero

Production implementation of GiyaHero, a Quezon-focused travel marketplace connecting travelers with verified travel agencies.

Android and iPhone source projects are in `mobile/`. Start with [mobile staging and release setup](docs/operations/mobile-release.md). The live marketplace supports agency-reviewed publication and persistent booking requests that require agency approval before confirmation.

The testing database has synthetic demo accounts for every role and a populated tour catalog. See [demo data setup](docs/operations/demo-data.md); private logins are in the ignored `.demo-seed/LOGIN-GUIDE.md` file.
